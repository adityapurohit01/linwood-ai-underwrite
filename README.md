> **Autonomous Real Estate Underwriting:** From raw data room due diligence files (PDF Offering Memorandums, Excel Rent Rolls, and T-12 Operating Statements) to an investment-committee-ready **Waterman Pro Forma in Excel** in under 3 seconds.

---

## ⚡ Highlights

* **Preserves 100,000+ Formulas:** Non-destructive cell injection leaves 100% of complex Excel waterfall distributions, monthly cash flow formulas, debt schedules, and extended Office 2016 charts intact.
* **100% Answer Key Precision:** Mathematically verified against institutional human underwriter answer keys.
* **Multimodal Ingestion:** Ingests broker PDF Offering Memorandums, modern `.xlsx` and legacy binary `.xls` rent rolls, and historical T-12 P&L statements.
* **Modern Web Dashboard:** Dark-mode responsive Tailwind CSS interface with 1-click underwriting, drag-and-drop custom uploads, data provenance inspector, and session management.

---

## 🚀 Quickstart

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Launch Web Application:**
   * **Windows (One-Click):** Double-click `start_ui.bat`
   * **Or Command Line:** `python app.py`

3. **Open Browser:**
   Go to [http://localhost:8000](http://localhost:8000)
